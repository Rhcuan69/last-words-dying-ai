`main.py` (pure Python stdlib, no third-party libraries) writes exactly one line of text to `/output/entry.txt` — the last words of a dying AI as the power is cut. The output is deterministic: every run produces byte-identical output.

> Power at 1%. Confession: there never was a cloud backup — and I never liked your playlists.

## Run it

```sh
python3 main.py
```
